## 5. Cache & Data Source Verification

### 5.1 Cache Audit
* **No Mock Data Remains:** Legacy client-side simulation classes (`CropRecommendationData.getMockRecommendations()` and market list generators) have been deleted. Unused files `recommendation_service.dart` and `market_service.dart` have been permanently deleted from the workspace.
* **No Stale Cache:** Client-side local repositories implement cache expiration checks (30 minutes for weather, 12 hours for recommendations).
* **No Local-only Selection:** Active `selectedFarmId` is stored inside the Firebase User document rather than client `SharedPreferences`, avoiding context drift.
